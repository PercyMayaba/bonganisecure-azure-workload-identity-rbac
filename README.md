# BonganiSecure Azure Workload Identity and RBAC Security Lab

## Project Overview

This project demonstrates practical Azure identity and access management engineering, focusing on securing application identities, service principals, managed identities and Azure resource permissions.

The project follows Microsoft identity security principles, Zero Trust architecture and least-privilege access control.

**Career focus:** Azure IAM Engineer / Cloud Security Engineer

## Project Objectives

- Understand Azure workload identity architecture.
- Configure and assess managed identities.
- Investigate app registrations and service principals.
- Implement Azure Role-Based Access Control (RBAC).
- Review excessive permissions and privilege assignments.
- Investigate workload identity security risks.
- Develop identity security recommendations.

## Project Modules

1. Azure workload identity architecture.
2. Managed identity configuration and security.
3. App registrations and service principal security.
4. Azure RBAC and least-privilege engineering.
5. Identity permissions and access reviews.
6. Workload identity security investigation.
7. Architecture documentation and final assessment.

## Security Engineering Approach

The project distinguishes between:

- Live Azure configurations that have been implemented and verified.
- Simulated security investigations.
- Planned controls that have not yet been deployed.

No implementation will be described as live unless it has been verified.

## Cost and Resource Controls

The lab prioritises existing Azure subscription resources, free capabilities and cost-conscious configuration.

Billable resources will not be created without first reviewing their potential cost.
